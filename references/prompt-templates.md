## 1. 变量与固定锁

约一半内容由任务变量决定，另一半锁定核心战斗语法。变量可替换上游角色与原创世界观，不得删减命中帧数、特效生命周期、音乐范围、八层声音、镜震、慢动作、音乐抽空参数以及 15/30/60 秒优先结构。

```yaml
input_mode: "{text_to_image | image_to_image | text_to_video | image_to_video | storyboard | local_motion_transfer}"
subject: "{角色、关系、目标、武器或能力、场景、当前动作}"
reference_roles:
  - file: "{参考文件}"
    role: "{identity | outfit | scene | composition | style | motion}"
output_spec: "{仅继承用户或上游给定规格}"
preserve: "{身份、人数、关系、姿势含义、构图、文字、道具、既定画风等}"
creative_direction: "{允许变化的角色设计、场景、剧情、镜头和强度}"
```

**固定风格锁：** 高可读高速写实 3D 动作；长静止短爆发；双向攻防与优势交换；预备—爆发—接触—命中停顿—反应—恢复/取消；地空连段、突进、瞬移接位、基础形态—觉醒/强化形态、终结对撞；角色专属武器人格；第三人称可读镜头配少量电影化插入；轨迹、能量源与接触点绑定特效；身体、服装、地面、碎片和环境共同响应；逐级升级与结果姿态。

## 2. 文生图

```text
任务：基于 {subject} 生成 {用途}。
主体与关系：{角色数量、身份、关系、武器或能力、服装、站位}。
叙事动作：{冲突原因}；只选择 {接触前一瞬 | 招架接触 | 击飞顶点 | 砸地接触 | 升级定姿 | 终结对撞} 一个峰值。写清攻击者起点、重心、武器弧线、接触点、防守者选择与受力方向。
构图与机位：{用户指定构图；否则第三人称中远景或过肩可读构图}，双方位置、距离和攻击线清楚；关键节点可用短暂低机位或电影化近景。
材质与光线：写实 3D 游戏过场质感，可信皮肤、发束、织物、皮革与金属，可信材质反射、体积光、接触光、暗部结构和轮廓分离。
动作与特效：长静止后的短爆发；刀光从刃口沿真实轨迹产生，接触点 1–3 帧硬亮核心；身体、服装、武器、地面和碎片按同一力量方向响应。
角色变量：{可替换上游角色；身份、脸、服装、武器、颜色、能力和关系由上游决定}，所有原创识别元素重新设计。
连续性：{continuity_lock 摘要}。
输出规格：{output_spec}。
必须保留：{preserve}。
负向约束：不复用既有作品的可识别人物外形、专属服装、标志武器、徽记、界面、台词、旋律或镜头复刻；所有角色和世界观元素依据上游输入重新设计。
```

## 3. 图生图

```text
输入模式：image_to_image / local_motion_transfer。
参考职责：
- {图 A}：负责 {身份/脸/服装/武器}。
- {图 B}：负责 {场景/构图/空间}。
- {内置参考帧，可选}：只负责 {动作弧/材质外观/镜头/特效层级}。

必须保留：{身份、人数、关系、五官、发型、服装、武器、姿势含义、站位、构图、文字、关键道具、背景布局、既定画风中适用项}。
允许改变：{被点名的动作姿态、材质表现、光线、环境反馈、特效或镜头强调}。
重绘规则：不是叠加滤镜；重新建立可信重心、攻击路径、接触点、受击方向、轨迹绑定刀光、接触光、服装滞后、地面裂痕和碎片响应。若仅迁移动作或运镜，冻结既定媒介、造型、材质和配色。

完整提示词：
{subject}；在不改变“必须保留”内容的前提下，将目标维度重绘为高可读高速战斗峰值。使用预备—爆发—接触—命中停顿—反应—恢复/取消的可见因果；当前画面停在 {峰值}。第三人称空间关系清楚，电影化近景仅在关键节点使用。特效绑定轨迹、能量源和接触点；身体、服装、地面、碎片和环境共同响应。写实 3D 游戏过场质感仅在 creative_direction 要求完整视觉迁移时使用。{continuity_lock}。输出规格仅继承 {output_spec}。
负向约束：不复用既有作品的可识别人物外形、专属服装、标志武器、徽记、界面、台词、旋律或镜头复刻；所有角色和世界观元素依据上游输入重新设计。
```

## 4. 文生视频

### 4.1 全局模板

```text
任务：创建 {时长}、{画幅}、{单镜头/多镜头} 的 {subject} 战斗视频；只继承 {output_spec}。
起始状态：{角色位置、距离、姿态、武器、伤势、场景、光线、可破坏物状态}。
固定语法：高可读高速战斗；长静止短爆发；双向攻防与优势交换；每个关键动作执行预备—爆发—接触—命中停顿—反应—恢复/取消；地面或空中连段、突进、瞬移接位、形态升级与终结对撞按剧情选择；强度逐级升级并以结果姿态收束。
动作与镜头：{分段时间轴}。主镜头采用第三人称中远景或过肩跟随，少量电影化插入只服务亮相、受创、升级或终结；接触瞬间不切走。
固定命中参数：轻击停顿 2–3 帧，重击 4–6 帧，终结 6–10 帧；轻击刀光 2–5 帧，重击 4–10 帧，终结 8–14 帧；残像 0.10–0.40 秒；普通冲击波 0.20–0.60 秒，终结冲击波 0.60–1.20 秒。
固定镜头时间：普通镜震 0.08–0.18 秒，重击或砸地 0.18–0.35 秒，终结 0.35–0.60 秒；关键命中慢动作 0.20–0.45 秒，终结慢动作 0.60–1.20 秒，随后恢复实时速度。
固定声音：105–115 BPM 工业金属/硬摇滚；环境、音乐、身体、武器、能量、命中、人声、余响八层。冲击前抽空音乐 0.10–0.30 秒，命中瞬态穿透，随后恢复层次并保留尾响。
环境响应：{刀痕、裂纹、灰尘、碎片、液体、火花、体积介质和可破坏物的因果响应}。
结束状态：{双方最终位置、姿态、伤势、武器、形态、场景破坏、光线、下一镜入口}。
连续性：{continuity_lock}。
负向约束：不复用既有作品的可识别人物外形、专属服装、标志武器、徽记、界面、台词、旋律或镜头复刻；所有角色和世界观元素依据上游输入重新设计。
```

### 4.2 优先时间结构

未指定结构时选用以下之一；用户指定其他时长时按相同阶段和因果适配。

**15 秒**

```text
0–2 秒：武器、眼神与站姿建立双方身份与距离。
2–6 秒：第一次交锋，快—快—停—重。
6–9 秒：防守方招架或瞬移反击，优势交换。
9–12 秒：代表技或形态升级改变规则。
12–14 秒：终结对撞或精确反击。
14–15 秒：结果姿态、收势与余响。
```

**30 秒**

```text
0–4 秒：场地、双方与冲突目标。
4–9 秒：试探和第一套短连招。
9–14 秒：反制与第一次受创或失位。
14–19 秒：远程、召唤、场景互动或空中段。
19–24 秒：形态升级并改变战场规则。
24–28 秒：最终攻防与主碰撞。
28–30 秒：余波和关系确认。
```

**60 秒**

```text
0–7 秒：关键亮相与目的。
7–17 秒：基础形态交锋。
17–27 秒：第一次优势交换与受伤。
27–37 秒：远程、空中或场景互动。
37–47 秒：形态或首领阶段升级。
47–56 秒：终局连段、反制与对撞。
56–60 秒：结果姿态、短台词或下一战钩子。
```

## 5. 图生视频

```text
参考职责：{逐张说明 identity/outfit/scene/composition/style/motion}。
必须保留：{第一帧的人物身份、人数、服装、武器、站位、构图、背景结构、既定画风}。
允许改变：{动作展开、镜头路径、环境破坏、特效与光线反馈}。
重绘规则：遮挡后身份不漂移；从图中已有力和方向继续，不突然反向或交换攻击者；设定图先转为单一角色与可战斗场地，不让多视图同时活动。
起始状态：精确复现 {首帧可见状态}。
主体动作：{以六段语法写每个关键动作和优势交换}。
环境响应：{与接触和受力同步的地面、碎片、衣摆、头发、光线}。
镜头运动：{第三人称可读路径；景别、机位、路径、速度曲线和结束构图}。
固定参数：沿用文生视频模板中的命中、刀光、残像、冲击波、镜震、慢动作、音乐抽空、105–115 BPM 与八层声音参数。
结束状态：{下一镜继承的人物、武器、方向、伤势、形态、场景和光线}。
连续性：{continuity_lock}。
输出规格：{output_spec}。
负向约束：不复用既有作品的可识别人物外形、专属服装、标志武器、徽记、界面、台词、旋律或镜头复刻；所有角色和世界观元素依据上游输入重新设计。
```

## 6. 连续性块

```yaml
continuity_lock:
  character_anchor: "{身份、脸、比例、发型、服装、伤势与形态}"
  scene_anchor: "{空间方位、地标、破坏状态、天气与时间}"
  material_anchor: "{皮肤、织物、皮革、金属、地面与能量外观}"
  light_anchor: "{主光方向、环境明暗、接触光与高亮回落}"
  camera_anchor: "{轴线、攻击方向、景别逻辑与上一镜结束构图}"
  motion_anchor: "{上一镜速度、重心、武器弧、接触结果与恢复状态}"
  prop_anchor: "{武器、关键道具、位置、握持和损坏状态}"
```

## 7. 负面约束

按任务裁剪：身份、人数、服装或武器漂移，额外肢体，关节断裂，手穿握柄，武器弯曲或穿模，角色融合，无接触受击，受击方向错误，刀光脱离轨迹，无来源爆炸，持续慢动作、镜震、模糊或白闪，摄影机丢失主体，频繁越轴，接触瞬间切镜，空间状态跳变，无关界面、评分、字幕、Logo 或水印。

统一加入：不复用既有作品的可识别人物外形、专属服装、标志武器、徽记、界面、台词、旋律或镜头复刻；所有角色和世界观元素依据上游输入重新设计。
