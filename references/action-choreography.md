## 1. 六段动作单元

每个关键动作依次写明：

1. **预备**：视线锁定、重心转移、武器后引、呼吸或能量聚集。
2. **爆发**：踏步、突进、瞬移、起跳或武器加速。
3. **接触**：刃口、拳脚、弹丸或能量在明确位置命中或被挡。
4. **命中停顿**：按轻击 2–3 帧、重击 4–6 帧、终结 6–10 帧确认力量。
5. **反应**：错步、屈膝、扭转、击飞、滑地、格挡回弹或反击。
6. **恢复/取消**：收势、落地、滑步、切换武器或接下一招。

动作级时间感：轻击预备 0.15–0.35 秒、爆发 0.08–0.20 秒、恢复 0.20–0.50 秒；重击预备 0.30–0.80 秒、爆发 0.15–0.35 秒、恢复 0.40–1.00 秒；终结预备 0.80–2.00 秒、爆发 0.20–0.60 秒、余波 1–3 秒。用于判断动作容量，不替代用户给定的视频时间规格。

## 2. 空间、重心与二级运动

- 先写双方相对距离，再写招式。瞬移也必须从已知起点到明确终点。
- 起步腿踩实，推动髋部和躯干后再带动武器；横斩由髋肩扭转，突刺由后腿推送，砸地由下坠重力和躯干折叠驱动。
- 命中后武器与身体保留惯性，用脚步、转身或滑动消解，不瞬间冻结。
- 外套、头发、带子、尾巴、翅翼比主体滞后，再超调回摆；只放大动作弧，不反向主导运动。
- 空中动作保持上升、悬停、横移和下坠的连续动量；落地必须有膝髋缓冲、抓地、滑步或翻滚。

## 3. 动作词库

### 接近与接位

- **缓步压迫**：上身稳定、武器低垂、脚步清楚，用于长静止段。
- **直线突进**：强踏步后沿最短路径逼近，背景拖影只沿运动方向。
- **侧闪切角**：横移避开攻击线，获得侧后角度并立即建立新朝向。
- **瞬移接位**：起点残像消散，终点先见方向提示，再接出招、架挡或落地。
- **空中俯冲**：高点短暂读出轮廓，再沿斜线加速下坠。

### 地面与空中攻击

- **斜上挑**：低姿起手，从下方击飞，作为空中连段入口。
- **双横斩**：第一击快且窄，第二击宽且推动对手侧移。
- **直线突刺**：最短路径，命中后保留身体前压和武器回弹。
- **回身重斩**：借前一击旋转惯性，停半拍后反向落下。
- **低扫破防**：攻击防守底部，迫使跳起、失衡或暴露上身。
- **砸地冲击**：落点明确，产生放射裂纹、尘圈和碎片。
- **挑空追身**：对手先离地，攻击者后追，不能同时无因上浮。
- **连续滞空击**：控制在 2–4 次重音，每击改变高度、朝向或防守状态。
- **下劈终结**：攻击者收膝或翻身后垂直下压，将对手砸回地面。

### 防守、反制与恢复

- **格挡**：在攻击线上形成稳定结构，保住位置但承受压力。
- **精准招架**：接触前切入，清脆火花与明确停顿后反向爆发。
- **闪避反击**：让攻击擦过前景，再从侧后方出现并出招。
- **以攻对攻**：两条轨迹在中心相撞，停顿后决定谁被弹开。
- **空间切断**：用召唤物、范围斩或环境迫使对手改线，再截击落点。
- **姿态恢复**：甩落能量、收势、擦血、扶武器起身、松肩或无言直视；只在安全距离或对手失衡时使用。

## 4. 连招与优势交换

每套连招只有一个主目标：逼退、破防、击飞、换位、压起身或终结。使用 3–5 个重音；每击改变距离、高度、朝向或防守状态；保留半拍停顿、假动作或读招；结束时明确双方位置和状态。

- **快—快—停—重**：轻击逼守 → 改角度 → 半拍观察 → 重击破防 → 对手滑退。
- **佯攻—招架—反转**：假突刺 → 对手抢攻 → 侧移招架 → 贴身反斩 → 双方拉开。
- **击飞—追身—砸地**：低扫迫跳 → 上挑击飞 → 空中两次追斩 → 垂直下劈 → 地面破裂。
- **压制—穿越—终结**：远程阵列建立攻击缝隙 → 对手高速切入 → 短交锋 → 贴身重击。
- **终局对撞**：双方退至两端 → 能量与音乐上升 → 相向冲锋 → 中央接触 → 固定停顿 → 单次爆发 → 结果姿态。

防守者必须在格挡、招架、闪避、抢攻或强化爆发中作选择，并承担相应代价。每 4–8 秒至少发生一次优势交换或战术变化；短于该范围的片段至少包含一次有效反制。

## 5. 角色专属武器人格

| 武器类型 | 动作性格 | 轨迹与节奏 | 声音动机 |
|---|---|---|---|
| 重剑或巨刃 | 宽幅、压迫、强惯性 | 大弧线、长恢复、身体旋转取消 | 厚风切、低金属撞击 |
| 细刃或单刃 | 直线、精准、克制 | 短预备、窄轨迹、出鞘与收势、强招架 | 尖锐出鞘、清脆接触、短尾响 |
| 双刃或短剑 | 贴身、连续、换角 | 左右交替、低位绕背、短恢复 | 薄风切、密集点响 |
| 拳套或腿甲 | 近身、爆发、身体重量 | 脚步与髋部驱动、短击退、强震动 | 闷击、护甲撞击、低频拳爆 |
| 长枪或长柄 | 控距、穿刺、扫荡 | 直线突刺与宽幅横扫交替 | 长风切、杆身震动、刃尖脆响 |
| 枪械 | 压制、取消、远程确认 | 后坐、连射节奏、明确命中点 | 机械动作、爆裂、弹壳与回声 |
| 召唤武器或术式 | 控场、追踪、组合 | 先布阵再发射，轨迹具队形 | 音高上升、空间撕裂、分层脉冲 |

颜色、元素和武器不固定绑定，按可替换上游角色重新分配。

## 6. 一对一、群战与首领战

### 一对一

双方轮流掌握主动权；用距离偏好、招架、闪避、武器差异和挑衅表现关系。每轮爆发后重新建立双方距离和朝向。

### 群战

摄影机与动作一次只强调一个主威胁，其余敌人用包围线、准备动作或远程提示保持存在。主角先通过位移整理敌人，再使用范围技，不能在中心对所有方向同时乱挥。

### 首领战

每阶段定义首领主动技、破防窗口、挑战者应对、场景变化、音乐变化和阶段结束动作。第一阶段建立规则，第二阶段打破一条旧规则并增加代价，终局用此前建立的能力或选择完成反制。

## 7. 摄影机协同

| 动作 | 摄影机 | 避免 |
|---|---|---|
| 对峙 | 中远景、轻环绕或慢推 | 过早高速绕圈 |
| 突进 | 过肩跟随、沿攻击线短推 | 反向运动抵消速度 |
| 横斩 | 侧向跟移或稳定三分构图 | 随刀光乱甩 |
| 击飞 | 抬升并略拉远，保留双方 | 丢失攻击来源 |
| 砸地 | 下压后按参数短震，展示裂纹 | 贴脸看不到落点 |
| 招架 | 接触前稳定，命中短推或停顿 | 接触瞬间切镜 |
| 升级 | 低机位或有限环绕，最终定姿 | 烟雾长期遮挡轮廓 |
| 终结对撞 | 广角对称或低位纵深，碰撞后拉开 | 多次白闪与随机切角 |

## 8. 15/30/60 秒结构

### 15 秒

- 0–2 秒：身份、武器、站姿与距离。
- 2–6 秒：第一次交锋，快—快—停—重。
- 6–9 秒：招架或瞬移反击，优势交换。
- 9–12 秒：代表技或升级。
- 12–14 秒：终结对撞或精确反击。
- 14–15 秒：结果姿态、收势与余响。

### 30 秒

- 0–4 秒：场地、双方与冲突目标。
- 4–9 秒：试探和第一套短连招。
- 9–14 秒：对手反制，第一次受创或失位。
- 14–19 秒：远程、召唤、场景互动或空中段。
- 19–24 秒：形态升级并改变规则。
- 24–28 秒：最终攻防与主碰撞。
- 28–30 秒：余波和关系确认。

### 60 秒

- 0–7 秒：关键亮相与目的。
- 7–17 秒：基础形态交锋。
- 17–27 秒：第一次优势交换与受伤。
- 27–37 秒：远程、空中或场景互动。
- 37–47 秒：双方形态或首领阶段升级。
- 47–56 秒：终局连段、反制与对撞。
- 56–60 秒：结果、短台词或下一战钩子。

用户指定单镜头时，把阶段改写为连续相机路径，不增加硬切；指定其他时长时保留阶段顺序并压缩或扩展动作容量。

## 9. 故障排查

- **看不懂谁打中谁**：减少粒子，延长起手，明确接触点与受击方向。
- **动作漂浮**：补脚下支撑、重心转移、武器惯性、落地缓冲和地面反馈。
- **连招均匀挥舞**：加入半拍停顿、假动作、招架或方向与高度变化。
- **瞬移随机闪烁**：补起点、目标、残像方向、抵达姿态与后续攻击。
- **镜头混乱**：回到过肩中远景，只在命中附近短推、镜震或切近景。
- **大招没有等级**：补蓄势、声音抽空、形态变化和结果，不只增加粒子。
- **对手像沙袋**：安排读招、防守选择、反击窗口与恢复动作。
- **人物变形或穿模**：减少同一时段动作数量，明确双手、武器和身体的相对位置。
